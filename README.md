## 🧠 Кто я

**Product-инженер и CPO WorkSync Systems.** Довожу продукт **от бизнес-ТЗ до прода**: архитектура → бэкенд → данные → деплой → эксплуатация. Люблю системы, которые тихо работают на масштабе и не будят по ночам.

```yaml
role:     CPO @ WorkSync Systems
focus:    операционные и аналитические платформы, мульти-парк SaaS
approach: продукт + инженерия + данные в одном лице
motto:    "от ТЗ до прода — и чтобы держало нагрузку"
```

- 🏗️ Строю **ParkOps** — единую операционную платформу парка развлечений: **7 модулей в проде**, мульти-парк CD, собственный маркетинговый DWH.
- 📊 Данные — второй родной язык: **ClickHouse-DWH**, сквозная атрибуция «реклама → сайт → звонок → сделка → касса», мульти-тач атрибуция (MTA).
- ⚙️ DevOps без страха: **build-once → registry → pull**, канарейка, авто-TLS, деплой на десятки парков с нулевым даунтаймом.
- 🎮 На стороне — **Chronicles: The Fracture**, PWA-RPG поверх реального мира (FastAPI + Next.js + PostGIS).
